Headroom
========

Claude Code の使用量（現在のセッション / 今週）を Mac のメニューバーに表示するアプリです。
Claude Code の「ステータスライン」機能と連携して動きます。

■ こんな人向けです
- Claude Code を Pro / Max プランのアカウントで使っている人
- ブラウザの claude.ai やデスクトップアプリ（チャット）だけを使っている場合は利用できません
- Claude Code を API キーで使っている場合も利用できません（プランの使用量がないため）

■ 動作に必要なもの
- macOS 14 (Sonoma) 以降（Apple シリコン / Intel 両対応）
- Claude Code（Pro / Max プランでログイン済み）

■ インストール
1. 「Headroom」を「アプリケーション」フォルダにドラッグしてください。
2. アプリケーションフォルダから Headroom を開きます。
   Dock には表示されず、画面上部のメニューバーにメーターのアイコンが出ます。

■ 初回起動で「開けません」と表示されたら
このアプリは Apple の公証を受けていないため、初回のみ次の操作が必要です。

1. 警告が出たら「完了」（または「OK」）を押して閉じる
2. システム設定 > プライバシーとセキュリティ を開く
3. 下のほうにある「"Headroom"は…」の横の「このまま開く」を押す
4. パスワードを入力し、もう一度「開く」を押す

■ Claude Code と連携する（最初に1回だけ）
1. メニューバーのアイコンをクリックし、「Claude Code と連携する」を押します。
2. Claude Code を使っている場合は、一度終了して起動し直してください。
3. Claude Code で何か送ると、使用量が表示されます。

連携すると、Claude Code の設定ファイル（~/.claude/settings.json）に
「ステータスライン」が追加されます。
- 元の設定ファイルは ~/.claude/settings.json.headroom-backup にバックアップされます。
- すでに自分でステータスラインを設定していた場合も、その表示はそのまま残ります。
- 設定（⚙）の「連携を解除」で、元の状態に戻せます。
- プロジェクトごとの設定（.claude/settings.json）でステータスラインを設定している
  フォルダでは、そちらが優先されるため使用量が更新されません。

■ 更新のタイミング
Claude Code が返答するたびに更新されます。
Claude Code を使っていない間は更新されません（最後の値と、何分前の値かを表示します）。
claude.ai のチャットで使った分は、次に Claude Code を使ったときに反映されます。

■ 通知
初回起動時に「通知を許可しますか？」と表示されたら「許可」を選んでください。
使用率が設定した段階（初期値 80% / 90%）を超えるとお知らせします。
段階を超えたあとは、リセットされたときにもお知らせします。

■ データの扱い
- Claude Code がステータスラインに渡す情報のうち、使用量（使用率とリセット時刻）だけを
  ~/Library/Application Support/Headroom に保存します。
- 会話の内容、作業フォルダの場所、ログイン情報は保存しません。
- インターネットには一切接続しません。

■ 注意
このアプリは Anthropic の公式アプリではありません。
Claude Code の仕様が変わると、表示できなくなる可能性があります。

■ アンインストール
1. 設定（⚙）>「連携を解除」を押す（Claude Code の設定を元に戻します）
2. メニューバーのアイコン > 「終了」
3. アプリケーションフォルダから Headroom をゴミ箱へ
4. （履歴も消す場合）~/Library/Application Support/Headroom を削除
